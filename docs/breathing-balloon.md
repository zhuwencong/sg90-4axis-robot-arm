# 呼吸气球：参数、接线与问答

[返回型号列表](../README.md)

**适用范围：ESP8266 D1 Mini 呼吸气球控制系统。** 这款不是机械臂，控制的是充气阀、抽气阀和真空泵。含控制板的套餐发货前已烧录对应程序。

## 信号口

| 部件 | 标识 | 控制信号 |
| --- | --- | --- |
| 充气阀 | `C` | `D5 / GPIO14` |
| 抽气阀 | `X` | `D6 / GPIO12` |
| 真空泵 | `P` | `D8 / GPIO15` |

表里是配套驱动模块的**信号输入**，不是给气泵或电磁阀供电的引脚。请断电按配套接线和气路图安装；不要把气泵、电磁阀本体直接接到 GPIO，也不要把机械臂的接线表套过来。

## 手机怎么用

1. 检查气路没有折弯、松脱，再上电。默认处于停止状态。
2. 连热点「呼吸气球（密码8个8）」，默认密码 `88888888`。浏览器输入 `http://192.168.4.1`；不要错输成机械臂的 `192.168.1.1`。
3. 首次调试请有人看守，从短时充气、抽气试起，确认方向正确后再开自动模式。出现异常，立即点停止，必要时切断电源。

## 买家常问

**手动一直充气或抽气，会自己停吗？** 单次手动动作由控制板计时，最长 12 秒。12 秒是软件上限，不代表气球或气泵可以安全连续运行这么久。自动模式不受这个单次限制，也不能靠关掉网页来停止；离开前先点停止并确认设备停下来。

**自动呼吸多快，能调吗？** 默认先抽气 2 秒，再充气 2.8 秒，约每分钟 12.5 次。资料对应的可调范围是每分钟 6–30 次。设备按时间控制，没有压力、流量或体积检测；不能把频率设置当成压力或充气量保证。

**断电后会自己启动吗？** 不会自动恢复动作。保存生效的参数可以在重启后保留，但重启仍是停止状态。

**想自己改程序怎么烧录？** 从[呼吸气球源码入口](https://gitee.com/zhouhao2528/maker-star-breath-balloon)取得对应工程，用 VS Code + PlatformIO 打开含 `platformio.ini` 的目录，选 `d1_mini`，用 USB 数据线连接，先 `Build` 后 `Upload`。网页已内置；请勿刷机械臂固件。
