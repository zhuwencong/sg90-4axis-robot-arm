# 四轴 SG90 夹子款：参数、接线与问答

[返回型号列表](../README.md)

**适用范围：四轴 SG90 夹子款，配套 ESP8266 NodeMCU V2 控制板。** 底座、大臂、小臂负责定位，第四个舵机负责夹爪张合，所以商品标题也写作“四舵机、3 自由度”。可在[淘宝四轴商品图文详情](https://item.taobao.com/item.htm?id=1027798435802)看夹子款整机实拍。真空泵款不是这份接线表的适用型号。

## 接线与供电

| 部位 | 指令 | 信号口 | 固件默认角度范围 |
| --- | --- | --- | --- |
| 旋转底座 | `X` | `D1 / GPIO5` | 0°–180° |
| 大臂 | `Y` | `D3 / GPIO0` | 46°–180° |
| 小臂 | `Z` | `D2 / GPIO4` | 60°–180° |
| 夹爪 | `E` | `D0 / GPIO16` | 45°–85° |

先断电，再接线。套装舵机的橙线接信号、红线接 5V、棕线接 GND。四路舵机参考 5V/2A 供电；如分开供电，控制板和舵机电源要共地。表里的角度是固件默认限位，而不是实物能在任何装配姿势下走到的角度。首次调试清空周围空间，逐路小幅试动。

## 上手与重新烧录

- 含控制板的套餐发货前已烧录，装好、接好线并上电即可开始连接。手机或电脑连热点「四舵机械臂（密码8个8）」，默认密码 `88888888`，在地址栏输入 `http://192.168.1.1/index.html`，不需要另装 App。
- 只想调动作，可以直接在网页上拖滑块；指令框输入 `X 90` 可让底座转到 90°，请确认移动路径没有障碍。
- 需要改程序才重新烧录。从[四轴源码入口](https://gitee.com/zhouhao2528/chuangkexingchenjixiebisiduo)取得对应工程，在 VS Code 的 PlatformIO 中打开含 `platformio.ini` 的目录，选 `nodemcuv2`，用能传数据的 USB 线连板，先 `Build`，再 `Upload`。网页内置，不用另传。

## 买家常问

**手机提示 Wi-Fi 没有互联网，怎么办？** 这是设备本地热点。保持连接，在浏览器地址栏输入上面的完整地址，不要当成搜索词。如果改过热点名称或密码，以板子实际设置为准。

**电脑没有串口？** 先换确认能传数据的 USB 线和 USB 口；仍不识别，再检查控制板对应的串口驱动，配套板资料标注为 CH340。

**舵机一直抖、发热或一动就重启？** 先断电，核对电源、插线、安装位置和机械限位。不要强扳、长时间堵转或反复上电。

**真空泵款或单买硅胶管能照这份图接吗？** 不能。真空泵款的外设引脚尚未核实，以对应实物和店铺确认的接线为准。单买硅胶管是气路配件，不需要接电或烧录。
