## 先看这三条

- **只想使用，不用重新烧录。** 确认接线后上电，手机连设备自己的 Wi-Fi，用浏览器打开对应地址。机械臂用 `192.168.1.1`，呼吸气球用 `192.168.4.1`。
- **同样是 D1 Mini，不等于可以混刷。** 五轴、六轴和呼吸气球的线路与固件不同；四轴夹子款的接线也不能套在真空泵款上。
- **问问题时带上型号。** 请提供套餐规格、控制板丝印和故障现象。不确定型号，先对照订单的规格名称和控制板，不要按某个通用教程试插。
